# SCANNER DE PODER

## Sobre o projeto

O **Scanner de Poder** é uma experiência interativa inspirada nos tradicionais **scouters de Dragon Ball**, desenvolvida para transformar o grito do usuário em uma representação visual de seu nível de poder.

Por meio do microfone do dispositivo, o sistema captura a intensidade sonora da voz e converte o resultado em um **nível de poder**, acompanhado por efeitos visuais, transformações e eventos especiais.

O projeto foi **produzido especialmente para a ENEL**, com foco em proporcionar uma experiência tecnológica, interativa e divertida ao público.

---

## Como funciona

O usuário ativa o microfone e grita em direção ao dispositivo.

O sistema:

1. Solicita acesso ao microfone.
2. Realiza uma calibração do ruído ambiente.
3. Analisa a intensidade do áudio captado.
4. Converte a intensidade do grito em um nível de poder.
5. Atualiza o medidor em tempo real.
6. Identifica a transformação correspondente ao nível alcançado.
7. Registra o maior poder atingido durante a sessão.
8. Ativa efeitos especiais conforme o nível de poder aumenta.

---

## Transformações

O Scanner possui sete níveis de evolução:

| Nível | Transformação     |
| ----- | ----------------- |
| 0     | FORMA BASE        |
| 1     | KAIOKEN           |
| 2     | SUPER SAIYAJIN    |
| 3     | SUPER SAIYAJIN 2  |
| 4     | SUPER SAIYAJIN 3  |
| 5     | SAIYAJIN BLUE     |
| 6     | INSTINTO SUPERIOR |

Ao atingir níveis elevados, o sistema intensifica os efeitos visuais, incluindo partículas, brilho, tremores, glitch e outros efeitos de sobrecarga.

## Como executar

O projeto pode ser executado em um navegador moderno compatível com a **Web Audio API** e acesso ao microfone.

Recomenda-se utilizar:

* Google Chrome;
* Microsoft Edge;
* Mozilla Firefox;
* Safari.

### 1. Baixe ou copie os arquivos

Certifique-se de que os três arquivos estejam na mesma pasta:

```text
index.html
style.css
script.js
```

### 2. Execute o projeto

Abra o `index.html` em um navegador compatível.

Para uma experiência mais estável com acesso ao microfone, recomenda-se executar o projeto através de um servidor local.

### 3. Permita o microfone

Ao clicar em:

**GRITAR AGORA**

o navegador solicitará autorização para utilizar o microfone.

Após permitir o acesso, aguarde a calibração e então:

**GRITE PARA AUMENTAR SEU PODER.**

## Experiência

O objetivo do projeto não é apenas medir o volume de um grito, mas criar uma **experiência interativa de entretenimento**, combinando tecnologia, design e elementos de cultura pop.

A progressão visual foi pensada para criar uma sensação de evolução:

```text
FORMA BASE
     ↓
  KAIOKEN
     ↓
SUPER SAIYAJIN
     ↓
SUPER SAIYAJIN 2
     ↓
SUPER SAIYAJIN 3
     ↓
SAIYAJIN BLUE
     ↓
INSTINTO SUPERIOR
     ↓
SCOUTER SOBRECARREGADO
```

Quanto maior a intensidade detectada, maior a resposta visual do sistema.
